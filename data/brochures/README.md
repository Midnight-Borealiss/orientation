# Brochures source

Les catalogues ISM couvrent PLUSIEURS ecoles chacun. Les deposer a plat ici,
sans sous-dossier :

```
data/brochures/Brochure_Master__MAJ2_2024__Groupe_ISM.pdf
data/brochures/ISM_bachelor_brochure.pdf
data/brochures/ISM_ONLINE_ISF_BROCHURE.pdf
```

L'ecole de chaque programme se deduit des TITRES DE SECTION a l'interieur du PDF
(« ECOLE DE MANAGEMENT », « MADIBA LEADERSHIP INSTITUTE », « ISM DIGITAL CAMPUS »...),
jamais du nom du dossier.

Le sous-dossier par ecole reste utilise seulement si une brochure ne concerne
qu'une seule ecole.

Inclure l'annee dans le nom du fichier renseigne meta.annee_source.
